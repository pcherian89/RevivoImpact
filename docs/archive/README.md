# Archive — superseded v1 documents

tool for multi-site sports foundations, built around the "Play Every Day" programme and the Greenpark early warning.

lifecycle, and the P0 review consolidated everything into `../00`–`../08`.

**They are kept for reference only. Do not build from them.** Where they disagree with the current documents, the
current documents win.
